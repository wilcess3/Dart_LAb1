# Описание
Консольное приложение «Анализатор оценок» на языке Dart. Программа принимает список оценок студентов и выводит статистику: средний балл, максимальную и минимальную оценку, а также текстовую оценку

## Запуск
1. Клонировать репозиторий:  `git clone https://github.com/wilcess3/Dart_Lab1.git`
2. Перейти в папку:  `cd lab1_dart`
3. Установить зависимости: `dart pub get`
4. Запустить:  `dart run`

## Что изучила
1) Я поняла, что в Dart нужно указывать тип переменной. В Python можно написать x = 5, и никто не следит за типом. А в Dart если скажешь, что переменная — число, то и хранить в ней можно только число

2) Разобралась с null. В Dart есть специальный значок ?, который говорит: «эта переменная может быть пустой». А если значка нет — значит, там точно что-то есть

3) Узнала про final и const. Это слова, которые запрещают менять переменную после того, как ей присвоили значение. В Python такого нет — там можно случайно перезаписать что угодно

4) Освоила списки, словари и множества. Научилась хранить данные в разных структурах и перебирать их. А ещё узнала, что такое анонимные функции — это когда функцию можно написать прямо на месте, не давая ей имени.

# Ответы на вопросы
1. В Python тип переменной определяется во время выполнения, и ошибка типа всплывёт только при запуске. В Dart тип известен на этапе компиляции, поэтому компилятор сразу укажет на ошибку. Это ускоряет разработку и делает код надёжнее

2. String — это гарантированно не-null строка. String? — это nullable-тип, который может содержать null. Для работы с String? нужно либо проверить на null, либо использовать операторы ? или ??

3. final — это защита на уровне компилятора.В Dart компилятор не даст присвоить новое значение, что предотвращает ошибки

4. Позиционный параметр передаётся по порядку: describePet('Барсик', 'кот'). Именованный — по имени: describePet(name: 'Барсик', species: 'кот'). Это удобнее, когда параметров много
